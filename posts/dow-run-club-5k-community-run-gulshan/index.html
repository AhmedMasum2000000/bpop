Dow Run Club 5K Community Run in Gulshan

গুলশানে ডাউ রান ক্লাবের ৫ কিলোমিটার কমিউনিটি রান

পড়ুন

  • VIEW POST ON INSTAGRAM ↗
  • ← HOME

A free 5 km morning run in Gulshan, built around movement, connection and consistency. Sign-up is essential and spots are limited.

"আমরা কিন্তু যাচ্ছি দৌড়াতে" — we're going running. @the.dowrunclub is hosting a free 5K community run in Gulshan, presented by @batabangladesh, and B-POP Tags is lacing up.

5K community run in Gulshan: the details

  • Where: Shahabuddin Park, Gulshan, Dhaka
  • Start time: 6:00 AM
  • Distance: 5 km
  • Cost: free registration
  • Spots: limited, and sign-up is essential

The post's hashtags include #fridaymorning, but it doesn't give a calendar date, so check the sign-up form before you set your alarm.

Quick checklist before race morning:

  • Register through the form linked below, since sign-up is essential
  • Plan to reach Shahabuddin Park before the 6:00 AM start
  • Bring friends: the run is open to runners, creators, students and professionals alike

More than a morning workout

The organisers describe it as "a morning built around movement, connection, and consistency." They're bringing together runners, creators, students and professionals who believe "the best communities are built one run at a time."

The cover leans into the city theme. "The Dow Run Club" and "City Run" sit in pixel-style type over a blurred, acid-green image of a runner with one arm raised, under a location pin for Shahabuddin Park, Gulshan.

How to register for the run

Registration is free but required. Sign up through the Dow Run Club registration form, and do it early, since the caption says spots are limited. Then, in the post's own words: come run, connect, and be part of the community. See you at the start line.

Why community runs matter

Not every gathering in the city needs a sound system. Morning runs like this one build the same thing a good party does: a crew of regulars who keep showing up for each other. The Dow Run Club's focus on consistency, one run at a time, is a reminder that community is something you practise. Where does the Dow Run Club 5K start?

At Shahabuddin Park, Gulshan, Dhaka. The run starts at 6:00 AM.

Is the Dow Run Club community run free?

Yes. Registration is free, but spots are limited and sign-up through the Google Form linked in the post is essential.

Who is presenting the run?

The run is organised by @the.dowrunclub and presented by @batabangladesh.
