# B-POP Tags — website

Editorial one-page site for **B-POP Tags (Bangla Pop Tags)** — curating pop-culture & the underground scene.

A content-driven site: every page is rendered from **`content/posts.json`** (one entry per Instagram post) and
**`content/articles/<slug>.json`** (the article for that post). Add or edit a post there and the site updates —
home sections, the post's own page, topic pages, the archive, sitemap and RSS feed.

```bash
npm install      # nothing to download — there are no dependencies
npm run dev      # dynamic server at http://localhost:5173 — pages render on every request
npm run build    # static export: generated pages into the repo root + full site into dist/
npm run preview  # serve dist/ as plain static files
```

Set `SITE_URL` (e.g. `SITE_URL=https://example.com/ npm run build`) so canonical URLs and the sitemap point at the
live domain. The default is the GitHub Pages address in `content/posts.json`.

### Deploy
- **Any Node host** (Render, Railway, Fly, a VPS): `npm start` — fully dynamic.
- **GitHub Pages**: Settings → Pages → Source: *GitHub Actions*. `.github/workflows/pages.yml` builds and publishes
  `dist/` on every push.
- **Static hosts** (Netlify, Vercel, Cloudflare Pages): build command `npm run build`, output folder `dist`.

### Adding a post
1. Add an entry to `content/posts.json` → `posts` (slug, Instagram code + URL, date, category, title, image, caption).
2. Put the cover image in `assets/ig/<code>.jpg`.
3. Write `content/articles/<slug>.json` (see an existing one for the fields: SEO title, meta description,
   keywords, Bangla title/summary, lede, markdown body, FAQ, related posts).
4. `npm run build` (or just refresh `npm run dev`).

## Structure

| Path | What |
| --- | --- |
| `index.html` | Home: loader, hero/about, Highlight, Guest, Other Episodes, Personality, footer, fixed bottom nav |
| `content/` | `posts.json` (all posts + topics) and `articles/` (one article per post) — the source of truth |
| `scripts/site.mjs` | Renders every page: home SEO + archive, `posts/<slug>/`, `topics/<topic>/`, `stories/`, sitemap, robots, RSS, 404 |
| `posts/`, `topics/`, `stories/`, `sitemap.xml`, `feed.xml`, `js/posts.js` | Generated by `npm run build` — don't edit by hand |
| `story.html?id=…` | Legacy story page; old links redirect to the matching post page |
| `js/data.js` | **All content** — highlights, guests, episodes, team, links. Edit this to update the site. |
| `js/core.js` | Shared helpers (`window.BP`): scroll/resize loop, reveal observer, marquees, parallax |
| `js/<section>.js` | One script per section: shell (loader/nav), hero, highlight, guest, episodes, personality |
| `css/<section>.css` | One stylesheet per section, plus `base.css` (tokens, shared utilities) and `story.css` |
| `scripts/` | Zero-dependency `serve.mjs` (dynamic server), `build.mjs` (static export) and `site.mjs` (page renderer) |
| `assets/` | Logo, mascot, tagline, and post artwork (`assets/posts/pNN.jpg`, cropped from the Instagram grid) |
